Privacy policy

プライバシーポリシー

最終更新日: 2026年10月12日

収集する情報

sui（以下「本アプリ」）は、氏名・メールアドレス・位置情報・端末識別子などの個人情報を収集しません。アカウント登録もありません。

写真の扱い

「撮る」で選んだ写真は、ラベルを読み取るときだけ、本アプリの中継サーバー（Cloudflare Workers）を経由して Google の Gemini API に送られます。中継サーバーは写真を保存しません。Google での取り扱いは Google の API 利用規約およびプライバシーポリシーに従います。読み取りに使った写真は、縮小したものがあなたの端末内にだけ保存されます。

AI 機能で送る情報

「香りの三択」「余韻の一句」「原型の物語」「店で」「sui と話す」は、あなたが許可したときだけ、銘柄の情報と、あなたの色暦（最近の記録・評価・ひとこと・選んだ言葉）、品書きの写真、話しかけた声を、本アプリの中継サーバー経由で Google の Gemini API に送って答えを作ります。声・写真・記録は中継サーバーに保存されません。設定画面の「AIに過去の言葉を渡す」を切ると送られなくなります。

端末内に保存する情報

記録（銘柄・評価・ひとこと・場所・写真）、保存した酒、地色の設定、年齢確認の結果は、お使いの端末内（ブラウザまたはアプリのローカルストレージ）にのみ保存されます。開発者や第三者のサーバーには送信されません。アプリを削除すると消去されます。

通信

本アプリが通信するのは、写真の読み取り（上記）のときだけです。ウェブ版では表示用フォントの取得のために Google Fonts に接続することがあります。広告配信・アクセス解析・トラッキングは行いません。

共有機能

「画像で共有」を押したときだけ、あなたが選んだアプリに、記録から作った画像を渡します。渡す内容は画面に表示されている画像のみです。

年齢

本アプリは酒類の情報を扱うため、20歳以上の方を対象としています。20歳未満の者の飲酒は法律で禁止されています。

価格・内容について

アプリ内の価格は公開情報をもとにした目安であり、販売店・時期により異なります。造り手の歴史などの説明は公開情報に基づきますが、正確性を保証するものではありません。
